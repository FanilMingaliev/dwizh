В каталоге есть PNG с русскими названиями (в терминале могут отображаться искажённо). Для **Android `res/drawable`** имена должны быть **a–z, 0–9, _** (без пробелов и кириллицы). Перед импортом в репозиторий: **переименовать** в стиле `ic_filter_city.png`, `bg_auth_decoration.png` и т.д.

- В **Color.png** из экспорта указан **main `#3B7FFA`**.

Перед финальным пиксель-пёрфектом **зафиксировать один hex** в Figma и в `DvizhColors.Brand`.

### Как использовать PNG в коде (план импорта)

1. **Малые иконки** (таббар, чипы): по возможности **дополнительно экспортировать из Figma по одному** (SVG или PNG 24/32dp) — с листа `Icons.png` в коде неудобно резать.
2. **Крупные фоны** (`Puzzle 1.png`): положить в `res/drawable-nodpi/` или `drawable-xxhdpi/`, в Compose `Image(painterResource, contentScale = Crop/Fit)`.
3. **Карточки** (`Card*.png`): на первом этапе — **заглушки** в `LazyColumn`; затем заменить на **Compose** (скругления, градиенты) + **Coil** для иллюстраций, если картинки пойдут с CDN.
4. **Чипы из Ideas.png**: в данных приложения завести **справочник тегов** (`id`, `title`, `categoryId`, `color`, `iconRes`); иконки — отдельные файлы или вектор из Figma.
